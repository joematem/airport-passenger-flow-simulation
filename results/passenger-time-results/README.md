# Passenger-time results

This folder will store end-to-end passenger-time measurements.

Suggested definition:

```text
passenger time in airport
= exit simulation time - airport entry simulation time
```

Planned outputs:

- mean passenger time;
- median passenger time if exported for external analysis;
- minimum and maximum;
- standard deviation;
- histogram / distribution;
- business versus economy comparison;
- Gate 1 versus Gate 2 comparison.

Recommended outputs:

```text
passenger-times.csv
passenger-time-histogram.png
passenger-time-summary.md
```

Do not report example values as measured results.
