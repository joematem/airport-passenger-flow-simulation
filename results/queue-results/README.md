# Queue results

This folder will store measured queue-performance outputs from controlled simulation runs.

Planned measures include:

- queue length over time;
- mean queue length;
- maximum queue length;
- time of peak congestion;
- comparison across baseline and capacity scenarios.

Recommended outputs:

```text
baseline-queue.csv
high-demand-queue.csv
queue-comparison.png
```

No numerical results should be added until they are generated by the model.
