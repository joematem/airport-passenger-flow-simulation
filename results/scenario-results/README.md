# Scenario results

This folder will store experiment comparisons.

Initial scenario plan:

| Scenario | Change |
|---|---|
| Baseline | Current airport configuration |
| High demand | Increased passenger arrivals |
| Added check-in capacity | More check-in service capacity |
| Added security capacity | More security service capacity |
| Departure surge | More closely clustered departures |
| Priority routing | Alternative business/economy logic |

Compare each scenario using the same KPI set where possible:

- passenger throughput;
- average passenger time;
- maximum queue;
- service utilisation;
- Gate 1 / Gate 2 passenger counts.

Recommended outputs:

```text
scenario-summary.csv
scenario-comparison.png
scenario-analysis.md
```
